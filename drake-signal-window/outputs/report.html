德雷克方程與射電通信時間窗口推論

此報告由 simulate.py 產生，直接讀取專案根目錄的 data.js。它不是在宣稱外星文明數量，而是把德雷克方程參數、射電通信窗口、光速延遲與既有功率門檻資料組合成可調情境。

This standalone report uses timing model normal and radio-window model fixed. Years on the probability curve are Earth receive years; source activity is evaluated at emit_year = receive_year - distance_ly, so light-speed delay is already included.

The normal timing model is retained as a symmetric baseline. The log-normal and gamma options are right-skewed alternatives for multiplicative development factors or prerequisite-accumulation processes. The log-normal radio-window model allows many short broadcast phases and a small number of very long phases. The infinite radio-window model treats civilizations as remaining radio-detectable after they become communicative; in that mode radio_window_years remains only a reference lifetime for the sparse Drake prior, not a shutdown time.

Rigor controls are enabled in this run: uncertainty spread 0.35, catalog selection bias 0.40, beam coverage 0.35, duty cycle 0.50, frequency coverage 0.45, and assumption correlation 0.25.

物理模型與學術背景推導 (Physical Modeling & Academic Background)

1. 能量常數 K 與最低可觀測通量 Fmin

所需等效全向發射功率（EIRP）計算公式為：P_required = K * d_ly^2，其中 K = 1.12 × 1011 W/ly2。

由物理關係 P = 4π × d2 × Fmin 換算（1 ly ≈ 9.4607 × 1015 m），可推導出對應的最低可偵測通量門檻：

Fmin = K / (4π × (9.4607 × 1015)2) ≈ 10-22 W/m2

這在射電 SETI 中代表一個 Jansky 等級的高靈敏度接收極限。例如，望遠鏡在 1.4 GHz (L-band) 的系統等效通量密度（SEFD）為 2 Jy 時，在 10 kHz 頻寬、300 秒積分時間與 S/N = 10 門檻下，其可偵測通量極限正好落在 10-22 W/m2 的量級。

2. 空間匹配半徑 0.2°

在與 Breakthrough Listen 進行觀測匹配時，設定天球夾角 ≤ 0.2°（12 角分）。這對應於 L-band (1.4 GHz) 下主流單口徑望遠鏡（如 Parkes 的 14' = 0.23° 或 GBT 的 9' = 0.15°）的半功率波束寬度（HPBW），確保目標系外行星位於望遠鏡觀測的半功率波束視場（FOV）內。

3. 卡爾達肖夫尺度 (Kardashev Scale)

發射功率分級對應卡爾達肖夫尺度：K_scale = (log10(P) - 6) / 10：

  • 地球級：P ≤ 1014 W (K_scale ≤ 0.8)
  • I 型文明：P ≤ 1016 W (K_scale ≤ 1.0)
  • 星際通信級：P ≤ 1020 W (K_scale ≤ 1.4，介於 I 型與 II 型之間的過渡狀態)
  • II 型以上：P > 1020 W (K_scale > 1.4)

4. 假說耦合模型 (Hypothesis Coupling)

模擬生命發生率 fl 與智慧生命率 fi 的關聯，反映生命與智慧是否有共同演化瓶頸的學術假說：

  • Independent (獨立模型): fl 與 fi 完全獨立抽樣。
  • Weakly Coupled (弱耦合): fi' = fi * (fl / 0.1)0.5
  • Strongly Coupled (強耦合): fi' = fi * (fl / 0.1)
  • Bottleneck (演化瓶頸): fi' 強制限制在 [0.001, 0.01]。
  • Rare Intelligence (稀有智慧): fl' = fl * 1.5 且 fi' = fi * 0.001。

5. 雙重生命尺度 (Dual Timescales)

將德雷克文明壽命 L 拆分為先驗強度 lPrior（用於確定文明曾經存在的總機率）與時間發射窗 tActive + tLeakage（用於計算訊號在空間中的波前寬度），避免重疊計算並支持「文明雖亡，信號仍在」的傳播場景。

6. 星表選擇偏誤 (Selection Bias)

星表完整度由 logistic 機率函數模擬：p_catalog = sigmoid(2.5 - selectionBias * 0.02 * d + 2.0 * q)，其中 d 為距離，q 為行星資料品質評分。此函數量化了因觀測限制對遠距離與低質量目標的篩選偏差。
